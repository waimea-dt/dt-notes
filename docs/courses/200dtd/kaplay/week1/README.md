# Week 1: Things That Move

This week you'll learn the basics of JavaScript, then use it to put things on the screen and make them move.

## Lessons

| Lesson | Title                                           | You will learn                                                                         |
| ------ | ----------------------------------------------- | -------------------------------------------------------------------------------------- |
| 1      | [Variables](/kaplay/week1/lesson1.md)           | `const`, `let`, strings, numbers, booleans, `console.log`, template literals           |
| 2      | [Choices and Repeats](/kaplay/week1/lesson2.md) | `if` / `else`, comparing values, `for` and `while` loops, functions                    |
| 3      | [Hello, Kaplay](/kaplay/week1/lesson3.md)       | Starting Kaplay, coordinates, `add([...])`, sprites, adding lots of things with a loop |
| 4      | [Make It Move](/kaplay/week1/lesson4.md)        | Keyboard input, `onUpdate`, speed variables, how the game loop works                   |

## Your prototype: Wander

By the end of the week your bean will wander around a haunted room, picking up gems while a row of ghosts watches from the top of the screen.

## Level Up ideas

- Stop the bean walking off the screen
- Add WASD keys as well as the arrow keys
- Make the bean flip to face the way it's walking
- Add a sprint key
- Show a "Gems left" counter on screen
