# Week 4: Scenes & Game State

This week you'll learn how to build a game out of separate **scenes**, like the rooms of a house, and how to keep track of the **state** of the game, such as the player's health and the items they're carrying. Then you'll design and build an adventure game of your own.


| Lesson | Title                                                              | You will learn                                                                       |
| ------ | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------ |
| 1      | [Rooms](/courses/200dtd/kaplay/week4-lesson1.md)                   | `scene`, `go`, doors between rooms, where variables live                             |
| 2      | [Hit Points](/courses/200dtd/kaplay/week4-lesson2.md)              | Global state, a HUD, hazards and pickups, game over, resetting the game              |
| 3      | [Inventory](/courses/200dtd/kaplay/week4-lesson3.md)               | An inventory array, `push` and `includes`, locked doors, rooms built from the state  |
| 4      | [Build a Haunted House](/courses/200dtd/kaplay/week4-lesson4.md)   | Designing and building your own adventure game                                       |


By the end of the week you will have built an adventure game of your own. Here's a haunted house, made with the pictures in the starter project. Find the key in the cellar, and unlock the attic... but watch out for the ghost!
