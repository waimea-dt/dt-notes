# Make Games with JavaScript and Kaplay

Welcome, game makers! Over the next five weeks you'll learn the JavaScript and the game-making tools you need to build your own game. Then you'll spend four more weeks designing and building it.

By the end you'll be able to make games with:

- characters you can move around
- enemies, bullets and explosions
- platforms, gravity and jumping
- story, dialogue and choices that matter

## How the course works

You're not going to sit and copy code for five weeks. Each lesson follows the same five steps, called **PRIMM**:

| Step | What you do |
|---|---|
| **P**redict | Look at some code. Write down what you think it will do. |
| **R**un | Run it. Were you right? |
| **I**nvestigate | Work out *why* it did that. Trace it, label it, poke at it. |
| **M**odify | Change the code and see what happens. |
| **M**ake | Build something new using what you've learned. |

Getting a prediction wrong is not a failure. It's the best moment for learning, because your brain just found out something it didn't know.

You'll also meet:

- **Parsons Problems**: the code is all there, but jumbled up. Put the lines in the right order.
- **Bug hunts**: something is broken. Find it and fix it.
- **Tracing tables**: act like the computer and work out the values, step by step.

## The ground rules

- We write **plain JavaScript**. No classes, no `this`. (You'll do those next year.)
- Games are built from **variables, functions, lists and Kaplay's `add([...])`**.
- Every week you finish one small **prototype**. It doesn't need to be a full game, it just needs to work and teach you something.
- Finished early? Every prototype has a **Level Up** list of extra challenges.

## Getting set up

Download the starter project: [kaplay-starter.zip](/kaplay/downloads/kaplay-starter.zip ':ignore')

1. Unzip it
2. Open the folder in VS Code
3. Start it with the **Live Server** extension (right-click `index.html`, then **Open with Live Server**). Double-clicking `index.html` won't load your pictures.
4. Edit `main.js`, save, refresh, repeat!

If you ever see a blank screen, press **F12** and look at the **Console** tab. Red text is the computer telling you what went wrong.
