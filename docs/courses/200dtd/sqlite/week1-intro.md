# Week 1: Asking Questions

This week you'll learn what a **database** is, and how to ask it questions with **SQL**. You'll pick out the columns you want, **filter** and **sort** the rows, and **summarise** whole tables. You'll finish by solving a case with nothing but queries.


| Lesson | Title | You will learn |
| ------ | ----- | -------------- |
| 1 | [Tables & SELECT](/courses/200dtd/sqlite/week1-lesson1.md) | Tables, rows and columns, `SELECT`, `ORDER BY`, `LIMIT` |
| 2 | [Filtering with WHERE](/courses/200dtd/sqlite/week1-lesson2.md) | `WHERE`, comparisons, `AND` / `OR`, matching text with `LIKE` |
| 3 | [Counting & Summaries](/courses/200dtd/sqlite/week1-lesson3.md) | `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `GROUP BY` |
| 4 | [Data Detective](/courses/200dtd/sqlite/week1-lesson4.md) | Answering a case file of questions with your own queries |
