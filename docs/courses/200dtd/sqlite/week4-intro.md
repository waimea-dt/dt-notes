# Week 4: SQLite in Python

This week your SQL moves into **Python**. You'll connect to a database, run queries, use **parameters** to keep things safe, and save changes. You'll finish by building a menu-driven **command-line app** on top of a database.


| Lesson | Title | You will learn |
| ------ | ----- | -------------- |
| 1 | [Connect & Query](/courses/200dtd/sqlite/week4-lesson1.md) | `sqlite3`, connecting, `execute`, `fetchall`, looping over rows |
| 2 | [Parameters & Changing Data](/courses/200dtd/sqlite/week4-lesson2.md) | `?` placeholders, SQL injection, `commit()`, query functions |
| 3 | [A Menu App](/courses/200dtd/sqlite/week4-lesson3.md) | Repo setup, a menu loop, tidy tables with f-strings, checking input |
| 4 | [Build a CLI App](/courses/200dtd/sqlite/week4-lesson4.md) | A command-line app to search, add, change and delete data |
