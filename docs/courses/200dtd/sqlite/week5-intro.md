# Week 5: Apps with Streamlit

This week your database gets a proper **user interface**. You'll use **Streamlit** to turn a Python script into a web app, with **widgets** to filter the data and **forms** to change it. You'll finish by building a Streamlit app of your own.


| Lesson | Title | You will learn |
| ------ | ----- | -------------- |
| 1 | [Hello Streamlit](/courses/200dtd/sqlite/week5-lesson1.md) | Running an app, showing data, how Streamlit reruns your script |
| 2 | [Widgets & Filters](/courses/200dtd/sqlite/week5-lesson2.md) | Text inputs, select boxes and sliders that drive your queries |
| 3 | [Forms & Changing Data](/courses/200dtd/sqlite/week5-lesson3.md) | Forms that add, change and delete data, with checks and messages |
| 4 | [Build a Streamlit App](/courses/200dtd/sqlite/week5-lesson4.md) | A Streamlit app to view, search and change a database |
