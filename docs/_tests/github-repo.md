# GitHub Repo Links

## With title and subtitle

<github repo="waimea-dt/kaplay-starter" title="Kaplay Starter" subtitle="A starter project to kick off your Kaplay games">

## Title only

<github repo="waimea-dt/dt-notes" title="DT Notes">

## Usage

```markdown
<github repo="OWNER/REPO" title="TITLE" subtitle="SUBTITLE">
```

No closing tag needed. `title` defaults to the repo name; `subtitle` is optional.
