# Pixel Art Tools

<!-- tool-lists -->

## Online Pixel Art Editors

- [Piskel](https://www.piskelapp.com/)
    - **Recommended**
    - **Online**
    - **Free**
    - Free pixel art editor
    - Create sprites and animations
    - Export as sprite sheets
    - Great for game dev

- [Pixilart](https://www.pixilart.com/)
    - **Online**
    - **Free**
    - Online pixel art tool
    - Community features
    - Free to use

- [Lospec Pixel Editor](https://lospec.com/pixel-editor/)
    - **Online**
    - **Free**
    - Simple and clean
    - Built-in colour palettes
    - Free


## Desktop Pixel Art Tools

- [Aseprite](https://www.aseprite.org/)
    - **Desktop**
    - **Paid**
    - Professional pixel art tool
    - Animation support
    - Paid (but worth it for serious work)

- [LibreSprite](https://libresprite.github.io/)
    - **Desktop**
    - **Free**
    - Free fork of Aseprite
    - Good alternative
    - Open-source

- [GraphicsGale](https://graphicsgale.com/)
    - **Desktop**
    - **Free**
    - Free pixel art tool
    - Animation features
    - Windows only
