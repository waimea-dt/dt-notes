## Vision Impairment Tools

- #### Browser **Dev Tools**
    - **Desktop**
    - Built-in to every browser
    - Look for **Accessibility** tab
    - Can simulate colour blindness

- [Web Disability Chrome Extension](https://chromewebstore.google.com/detail/web-disability-simulator/olioanlbgbpmdlgjnnampnnlohigkjla)
    - **Recommended**
    - **Online**
    - Quicker than accessing dev tools
    - Simulates a range of visual impairments

- [Colour Blind and Low Vision Firefox Add-On](https://addons.mozilla.org/en-US/firefox/addon/colorblindfyi/)
    - **Recommended**
    - **Online**
    - Quicker than accessing dev tools
    - Simulates a range of visual impairments
