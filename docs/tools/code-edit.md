# Code Editors and Integrated Development Environments (IDEs)

<!-- recommendations -->

## General Code Editors

- [Visual Studio Code](https://code.visualstudio.com/)
    ![Visual Studio Code logo](_assets/code.svg)
    - **Recommended**
    - **Desktop**
    - **Free**
    - Very popular and powerful
    - Customise via extensions
    - Built-in Git support

- [Zed Editor](https://zed.dev/)
    ![Zed Editor logo](_assets/zed.webp)
    - **Desktop**
    - **Free**
    - Clean, fast and modern
    - Good for web development
    - Still in development


## Python IDEs

- [Thonny](https://thonny.org/)
    ![Thonny logo](_assets/thonny.webp)
    - **Desktop**
    - **Free**
    - Simple interface
    - Built-in debugger
    - Perfect for learning Python

- [Spyder](https://www.spyder-ide.org/)
    ![Spyder logo](_assets/spyder.webp)
    - **Desktop**
    - **Free**
    - Scientific Python IDE
    - Good for data analysis
    - Variable explorer

- [PyCharm](https://www.jetbrains.com/pycharm/)
    ![PyCharm logo](_assets/pycharm.svg)
    - **Desktop**
    - **Free**
    - Free Community Edition
    - Professional IDE from JetBrains
    - Excellent for larger projects


## Kotlin IDEs

- [IntelliJ IDEA](https://www.jetbrains.com/idea/)
    ![IntelliJ IDEA logo](_assets/intellij.svg)
    - **Recommended**
    - **Desktop**
    - **Free**
    - Free Community Edition
    - Professional IDE from JetBrains
    - Excellent Kotlin support
