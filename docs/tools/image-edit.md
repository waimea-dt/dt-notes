# Image Editing Tools

<!-- tool-lists -->

## Simple Single-Task Tools

- [Remove Background](https://remove.bg)
    - **Recommended**
    - **Online**
    - Really simple and effective
    - Any image format to PNG

- [Image Cropper](https://10015.io/tools/image-cropper)
    - **Online**
    - Simple to use
    - Various aspect ratios, etc.

- [Image Resizer](https://10015.io/tools/image-resizer)
    - **Online**
    - Simple to use
    - Preserve aspect ratio


## Full Image Editors

- [Photopea](https://www.photopea.com/)
    - **Recommended**
    - **Online**
    - Similar to Photoshop
    - No installation needed
    - Free

- [Krita](https://krita.org/)
    - **Free**
    - **Desktop**
    - Digital painting and illustration
    - Great for game art
    - Free and open-source

- [Paint.NET](https://www.getpaint.net/)
    - **Free**
    - **Desktop**
    - Simple but powerful
    - Windows only

- [GIMP](https://www.gimp.org/)
    - **Free**
    - **Desktop**
    - Professional image editor
    - Free and open-source
    - Cross-platform
    - Similar to Photoshop
