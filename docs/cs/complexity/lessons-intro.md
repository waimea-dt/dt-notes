# Algorithmic Complexity

## Algorithm

An algorithm is a **set of steps or instructions**:

1. Put a teabag in the cup
2. Pour in boiling water
3. Wait for 1 min, then remove teabag
4. Add a splash of milk
5. Drink!

---

## Computer Algorithm

Computer algorithms are more formally written using a **programming language**:

```python
def sum_array(array):
  total = 0
  for item in array:
    total += item
  return total
```

---

## Effort

Algorithms require **effort** to run...

+++ list

- Each step requires **CPU** time
- Data requires **memory** to store it

---

## Complexity

Complexity is the **measure of the effort required**
