# 1980s - The Rise of the Personal Computer

80s INTRO HERE

<timeline>

- 1980: Osborne 1

	The Osborne 1 was an early portable computer. Although it weighed about 24 pounds, its suitcase-sized form showed that computers did not always have to stay in a room.

- 1981: IBM PC

	IBM introduced its first personal computer, code-named Acorn, using an Intel processor and Microsoft's MS-DOS. It helped popularise the term PC and created a widely copied hardware standard.

- 1983: Apple Lisa

	Apple's Lisa combined a graphical interface, icons and pull-down menus.

- 1983: Gavilan SC

	The Gavilan SC was among the first computers marketed as a laptop, using the now-familiar hinged form.

- 1983: C++

	Bjarne Stroustrup began developing C++, extending C with object-oriented programming features. It became a major language for systems and application software.

- 1984: Macintosh

	Apple released the Macintosh with a graphical interface and mouse.

- 1984: CD-ROM

	CD-ROM technology offered a large, durable medium for distributing software and reference material.

- 1985: Windows 1.0

	Microsoft released Windows 1.0 as a graphical environment for MS-DOS. It was a pretty terrible system with limited functionality. Ironically, it didn't even have overlapping Windows.

- 1985: Amiga 1000

	Commodore's Amiga 1000 stood out for advanced audio and video capabilities.

- 1988: The Morris worm

	The Morris worm spread across the early Internet and demonstrated that networked computers could be disrupted by malicious software, helping establish computer security as a major concern.

- 1989: The World Wide Web is proposed

	Tim Berners-Lee proposed the World Wide Web at CERN, combining hypertext with Internet networking so documents could be linked and accessed across different computers.

- 1989: Game Boy

	Nintendo's Game Boy showed how a compact, low-power computer could become a mass-market games platform.


</timeline>
