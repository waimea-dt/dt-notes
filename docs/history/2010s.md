# 2010s - Cloud Computing and Big Data

Web applications and large online services shifted more storage and processing away from individual computers and into data centres, laying the groundwork for modern cloud computing.

<timeline>

- 2010s: Cloud services become ordinary infrastructure

	Online storage, hosted databases and on-demand computing became standard tools for organisations, allowing software to scale without every team owning its own servers.

- 2010s: Smartphones and apps mature

	Faster mobile networks and capable smartphones made apps, cameras, maps, payments and social communication part of everyday computing.

</timeline>
