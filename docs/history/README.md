# The History of Computing

<speak>

![Mac](../_assets/macs/macintosh-idea.svg)

The **History of Computing** is long and full of amazing innovation and creativity.

</speak>


Back in the 19th Century, people had created mechanical calculating devices. However, these were not programmable - they always did the same operations. The first **programmable, digital computers** were created in the 1940s during World War II. From that point forwards, their development accelerated exponentially...
