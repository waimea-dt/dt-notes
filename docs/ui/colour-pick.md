# Colour Picker

This colour picker allows you to choose a **primary** and **accent** colour and see how they look on a mock-up UI, using various shades (lighter / darker variants).

Features:
- <i data-lucide="swatch-book"></i> Range of lighter / darker **shades** / **tones** for each colour
- <i data-lucide="link"></i> Accent **linked** to primary - **complementary** colour (but can be unlinked)
- <i data-lucide="shuffle"></i> Generate **random** colours
- <i data-lucide="arrow-left-right"></i> Primary and accent can th **swapped**
- <i data-lucide="check"></i> Can **disable** the accent colour
- <i data-lucide="sun-moon"></i> Switch between **light / dark mode** variants
- <i data-lucide="crosshair"></i> Click icon to **focus** instead on any colour swatch
- <i data-lucide="copy"></i> Click icon to **copy** any colour swatch
